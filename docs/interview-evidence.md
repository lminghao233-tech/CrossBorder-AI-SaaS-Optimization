# Interview evidence guide

## What can be claimed

- A runnable, risk-first multilingual routing prototype.
- Deterministic PII masking for several common identifiers.
- A 600-record **synthetic** benchmark with reproducible metrics.
- 28 automated tests, 97% package branch coverage and GitHub Actions that run
  without paid APIs.
- A modeled comparison against a premium-only baseline.

## What must not be claimed

- The synthetic tickets are real K-Trade customer tickets.
- The modeled price table is a current provider invoice.
- Keyword classification is a trained BERT model.
- Benchmark accuracy is production accuracy.
- This repository directly performs refunds, legal decisions or production
  model calls.

## Honest background statement

"The project is a portfolio-safe abstraction of recurring cross-border support
patterns: routine logistics/account questions are frequent, while legal, tax and
high-value cases have a higher failure cost. Because company data and interfaces
cannot be published, I rebuilt the decision logic with deterministic synthetic
Chinese, English and Korean samples. The public benchmark is fully reproducible;
it demonstrates the method rather than claiming production traffic results."
