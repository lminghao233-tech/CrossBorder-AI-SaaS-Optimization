# Synthetic benchmark methodology

## Dataset

- 600 deterministic synthetic tickets generated by `core.synthetic_data`.
- Languages: Chinese, English and Korean.
- Intents: logistics, account, product, refund, legal dispute and tax compliance.
- Distribution: 88% routine and 12% high risk.
- Every tenth sample is deliberately ambiguous and contains no routing keyword.
- All records carry `synthetic: true`; no customer or production record is used.

## Metrics

- Intent accuracy: exact expected-intent match.
- Economy route rate: share of requests routed to the economy model.
- High-risk premium recall: share of expected high-risk samples routed premium.
- Modeled cost reduction: premium-only baseline versus routed cost.

The price table is a stable benchmark assumption rather than a current vendor
quote. Input and output are fixed at 120 and 180 tokens per ticket to isolate
routing behavior. The benchmark is useful for regression, not for estimating a
real company's monthly bill.

## Reproduce

```bash
python -m core.benchmark --count 600 --output benchmark/results.json
python -m unittest discover -v
```
